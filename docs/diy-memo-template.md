# DIYメモのテンプレート

コピーして `inbox/experience/diy/YYYY-MM-DD_作業名.md` で保存してください。写真は同じフォルダに置き、ファイル名を下に書きます。
箇条書きのままで大丈夫です。書いてないことは記事に書きません。

```
## 作業名

## 作業前の状態
- 
- 写真: before1.jpg

## やったこと（順番に）

2. 
- 写真:

- 費用合計：

-
```
