# DIYブログ工程（朝ジョブの最後に実行）

CLAUDE.md「媒体2：DIYブログ」に従う。

## 0. 既存記事の点検（初回だけ）
- `output/blog/audit.md` がなければ作る。https://diyfamiliar.hatenablog.com/ の記事一覧（`/archive` をたどる）から全記事を見て、表にする：
  | 記事URL | タイトル | 公開日 | アフィリエイト・紹介リンクの有無 | PR表記 | DIYとの関係 | 提案（PR表記追加／非公開／リライト／そのまま） |
- 直すのは社長。AIは記事を書き換えない。

## 1. 材料の確認
- `inbox/experience/diy/` に、`output/blog/posted.md` にまだ載っていない新しいメモがあるか確認する。
- なければ「材料なし」と報告して終わる。

## 2. 記事を作る（材料がある場合、1日1本まで）
1. writer：メモから記事を書く。材料が足りなければ質問リストを作って終わる。
2. humanizer：AI感を除去する。
3. editor：§3（景表法・ステマ規制）と D1〜D5 を判定。メモとの照合も行う。NGなら writer に差し戻す。

## 3. 下書きアップロード
- editor のOKが出た記事だけ：
  ```
  python scripts/hatena_post.py output/blog/approved/<記事>.md --category DIY --category <カテゴリ>
  ```
  カテゴリはブログの既存カテゴリ（リビングリフォーム、キッチンリフォーム、砂壁 など）から選ぶ。
- 環境変数がなく失敗した場合はアップロードせず、「はてなAPIキー未設定」と報告する。
- 成功したら `output/blog/posted.md` に「日付｜タイトル｜確認URL｜元にしたメモ」を追記する。

## 4. 報告
- CLAUDE.md §5 の形式で、朝ジョブ全体の報告に含める。「社長確認待ち」には「はてなの下書きを確認して公開してください」と書く。
